# Texas Law Officer AI — GitHub Pages

## Upload
Upload ALL files in this folder to the root of a GitHub repository:
- index.html
- style.css
- app.js
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Do not upload the ZIP itself as the website.

## Enable GitHub Pages
Repository → Settings → Pages
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

GitHub will provide the public Pages URL.

## Important
This is the installable web-app frontend/prototype. It does not contain an AI API key and does not yet connect to a legal-research backend. Do not enter confidential or identifying information.
